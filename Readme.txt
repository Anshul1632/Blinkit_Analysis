🛒 Blinkit Sales Analysis Dashboard


The Blinkit Sales Analysis Dashboard is an interactive Power BI project designed to analyze sales performance, customer satisfaction, and outlet operations. It provides a comprehensive view of key business metrics through dynamic visualizations, enabling users to identify trends, compare outlet performance, and make data-driven decisions.

The dashboard focuses on analyzing sales across different product categories, outlet types, outlet sizes, and locations while monitoring essential KPIs such as Total Sales, Average Sales, Number of Items Sold, and Average Customer Ratings.

Key Features
Sales analysis by Fat Content
Sales analysis by Item Type
Outlet-wise sales comparison
Sales by Outlet Size and Location
Sales trend based on Outlet Establishment Year
KPI comparison across different Outlet Types
Interactive filters and slicers for dynamic analysis

This project demonstrates the use of Power BI, Power Query, DAX, and data visualization techniques to transform raw business data into meaningful insights that support strategic decision-making.
